# Introduction Review

## Review job

Check whether the Introduction creates a defensible problem-gap-action-contribution arc.

## Checks

Expect:

- urgency or importance in the opening
- visible gap by paragraph 2
- explanation of why the gap is hard
- clear paper action before method details dominate
- concrete contribution list

Block if:

- contribution bullets contain unsupported headline claims
- introduction promises results not in the paper
- gap statement misrepresents prior work

Revise if:

- opening is generic background
- gap is vague
- contribution list is a task list rather than claim list
- related work is dumped into the introduction

## Output focus

For each issue, say whether it is:

- gap problem
- contribution problem
- evidence problem
- flow problem
