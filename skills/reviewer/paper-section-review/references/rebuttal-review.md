# Rebuttal / Response Review

## Review job

Check whether rebuttal or revision response is professional, evidence-backed, and tied to manuscript changes.

## Checks

Expect each response to:

- acknowledge the reviewer point
- answer directly
- identify the manuscript change
- point to location
- provide evidence when disagreeing

Block if:

- response invents evidence
- response denies a real unsupported claim problem
- response promises changes not made in the manuscript

Revise if:

- response says only "fixed" or "clarified"
- response blames reviewer misunderstanding
- response is defensive rather than corrective

## Output focus

For each weak response, require:

```text
Reviewer concern:
Current response issue:
Required manuscript change:
Required response rewrite:
```
