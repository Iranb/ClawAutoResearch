# Figures, Tables, and Captions Review

## Review job

Check whether visual evidence supports the story.

## Figure checks

Expect:

- one figure, one main question
- clear axis labels, units, legends, and settings
- visible takeaway
- consistency between caption and body text

Block if:

- figure or caption supports a materially false claim
- caption asserts something not shown
- a central claim relies on an unreadable or missing figure

Revise if:

- caption is generic
- figure is decorative
- table mixes unrelated results
- metric direction or units are unclear

## Output focus

For each problem figure/table, state:

```text
Artifact:
Issue:
Claim affected:
Required fix:
```
