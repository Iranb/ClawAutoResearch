# Self-Attack Protocol

## Novelty Attack
- Ask whether the contribution sounds new only because the wording is broad.
- If the same idea could be described as a baseline tweak, narrow the story immediately.

## Overclaim Attack
- For every major sentence in the abstract and introduction, ask which table, figure, or experiment bundle defends it.
- If no answer is available, weaken or remove the sentence.

## Drift Attack
- Check whether Method, Experiments, and Discussion still support the same core thesis.
- If sections drift toward different paper messages, revise the story before polishing prose.

## Limitation Attack
- Ask what the strongest reviewer limitation would be.
- State that boundary explicitly before the reviewer uses it against you.
