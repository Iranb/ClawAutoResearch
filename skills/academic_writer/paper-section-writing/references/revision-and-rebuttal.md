# Revision and Rebuttal

Use this file when revising a full draft or preparing response-to-reviewer text.

## Four-pass revision order

Do not polish sentences first.

1. Claim pass
   - Is the main claim clear?
   - Is it supported?
   - Is anything overclaimed?
2. Structure pass
   - Do figures and sections follow a logical order?
   - Does Introduction align with Results?
3. Paragraph pass
   - Does each paragraph carry one job?
   - Can the section be reverse-outlined?
4. Sentence pass
   - Is the prose direct, specific, and low-friction?

## Low-friction English checks

Revise sentences that:

- bury the main verb
- begin with unexplained new information
- end without emphasis
- use too many nominalizations
- sound translated or inflated

## Rebuttal / response principles

Every response should:

1. thank the reviewer briefly
2. answer the issue directly
3. say what changed in the manuscript
4. point to the changed location
5. provide evidence when disagreeing

## Response template

```text
We thank the reviewer for raising this point.
We agree that ...
We have revised Section [X] to ...
Specifically, we now ...
This change clarifies ...
```

## When disagreeing

```text
We respectfully disagree with the interpretation that ...
The reason is ...
To make this clearer, we have added ...
```

## Hard rules

- Do not say "fixed" without explaining the manuscript change.
- Do not blame the reviewer for misunderstanding.
- Do not answer a writing problem with only rebuttal prose; revise the paper.
