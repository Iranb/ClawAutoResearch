# Story Planning Rules

## Rule 1: Story before prose
Lock the task, challenge, insight, contribution, and advantage before paragraph-level polishing.

## Rule 2: Contributions before sections
Decide the real contributions first, then let section structure follow them. Do not let section templates invent contributions for you.

## Rule 3: Anchor figure before paragraph sprawl
Choose the primary anchor figure before long drafting sessions so the prose explains a visual backbone rather than drifting.

## Rule 4: Fallback narrative before overclaiming
Write the fallback narrative before the main introduction is frozen. If the main story weakens later, the paper should already know how to tighten scope.

## Rule 5: Rejection simulation before outline freeze
Before locking the outline, run reject-first simulation, novelty attack, and unsupported-claim review so the structure reflects the real defense burden.
