# Full-Paper Consistency Review

## Review job

Check whether the full paper tells one coherent, evidence-backed story.

## Cross-section checks

Expect consistency across:

- title
- abstract
- introduction
- contribution list
- results
- limitations
- conclusion

## Block if

- abstract and results disagree
- introduction promises a contribution absent from results
- conclusion broadens beyond evidence
- terminology drift changes claim meaning
- central evidence appears only outside main text

## Revise if

- sections are locally good but story order is weak
- contribution wording changes across sections
- Figure 1 does not match the paper's main arc
- related work positioning does not match introduction claims

## Output focus

Return:

```text
Central claim:
Sections aligned:
Sections inconsistent:
Required fixes:
Verdict:
```
