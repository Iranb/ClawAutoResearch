# PaperGuru Prompt Pack

Use this skill when drafting, reviewing, or planning a research manuscript needs
the PaperGuru writing, figure-prompt, or scientific-editing prompt framework.

This pack is reference material, not a global system prompt. Load only the
reference file needed for the current stage:

- `references/writing-prompts.md` for writing standards, citation discipline,
  section expectations, tables, math, and anti-pattern rejection.
- `references/figure-prompts.md` for prompt-only concept figures, architecture
  figures, placeholders, and real-data routing.
- `references/editing-pass-prompts.md` for the six-pass scientific editing plan.
- `references/literature-query-prompts.md` for PaperNexus query-profile inputs.

Operational rules:

1. Treat PaperNexus artifacts as the evidence boundary.
2. Use prompt-only figures by default; do not fabricate real result graphics.
3. If image generation is enabled, use the project figure contract and receipts.
4. Do not change citation, compile, or submit gate behavior from this skill.
