# Figures, Tables, and Captions

Use this file when drafting figure plans, captions, or figure/table prose.

## Figure-first workflow

Before full drafting, list 4-8 key figures or tables:

```text
Figure X
Question:
Comparison / visualization:
Takeaway:
Claim supported:
```

Use the figure order to reverse-engineer the Results order.

## Caption template

```text
Figure X. [What is being compared or visualized].
Compared with [baseline / condition], [method / phenomenon] ...
This pattern suggests that ...
```

## Hard rules

- One figure should answer one main question.
- Captions should be mostly self-contained.
- Axis labels, units, legends, and settings must be clear.
- Do not include a figure just because it looks impressive.
- Do not let caption claims exceed the plotted evidence.

## Table rules

- Use clean table structure.
- Keep metric direction visible, e.g. `Accuracy ↑`, `Error ↓`.
- Use consistent precision.
- Do not mix unrelated experiments into one table.
- Highlight only what readers should notice.

## Ready check

A figure/table is ready only if:

- the reader knows what question it answers
- the takeaway is visible
- the figure supports a claim in the text
- the caption does not require excessive prose elsewhere
