# Results / Experiments Review

## Review job

Check whether Results prove the paper's claims.

## Checks

Expect:

- question-first subsection structure
- strong and relevant baselines
- clear metric direction and protocol
- ablations for core design claims
- robustness, cost, or failure analysis when needed

Block if:

- a headline result is unsupported
- text materially overstates numbers
- baseline or metric framing is misleading
- negative result is hidden in a way that changes the conclusion
- main claim depends on appendix-only evidence

Revise if:

- subsections report experiments without stating the question
- numbers are repeated without interpretation
- caveats are missing
- figures/tables do not have clear takeaways

## Output focus

For every major claim, map:

```text
Claim:
Evidence:
Status: supported / partial / unsupported
Required fix:
```
