# Results / Experiments

Use this file when drafting or revising Results or Experiments.

## Section job

Results should prove the paper's claims. It should not merely report what was run.

## Question-first structure

Each subsection should answer one reviewer question:

```text
Does it work?
Why does it work?
What component matters?
How does it compare to the strongest baseline?
When does it fail?
What does it cost?
```

## Results paragraph template

```text
We first ask whether ...
Figure / Table X shows that, compared with [baseline], our method ...
This result suggests that ...
```

## Evidence package

Strong Results sections often include:

- main comparison
- strongest baseline comparison
- ablation
- robustness / sensitivity
- failure cases
- cost / resource analysis
- reproducibility details

## Hard rules

- Do not use weak baselines as the only comparison.
- Do not report numbers without interpretation.
- Do not claim causality from a comparison that does not isolate a variable.
- Do not hide negative results that materially change the conclusion.
- Do not put key proof only in the appendix.

## Ready check

Results are ready only if:

- every major claim has evidence
- every figure/table has a takeaway
- limitations are visible where needed
- the strongest results match the Abstract and Introduction
