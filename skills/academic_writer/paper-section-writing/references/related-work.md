# Related Work

Use this file when drafting or revising Related Work.

## Section job

Related Work should position the paper. It is not a citation dump.

It must answer:

1. What lines of work are closest?
2. What do they accomplish?
3. What do they still miss relative to this paper's gap?
4. How is this paper different?

## Paragraph template

```text
Prior work on [problem] can be broadly grouped into [two / three] lines.
The first line focuses on ...
The second line focuses on ...
Despite their differences, these approaches share a common limitation: ...
Our work differs in that ...
```

## Organization

Use 2-4 technical groups:

- closest baselines
- methods with similar mechanisms
- adjacent tasks or settings
- surveys / benchmarks / datasets when relevant

## Hard rules

- Include the strongest relevant baselines.
- Do not hide inconvenient prior work.
- Do not exaggerate differences.
- Do not summarize one paper per sentence for long stretches.
- Do not say "unlike all previous work" unless you can defend it.

## Ready check

Related Work is ready only if:

- each group has a clear topic sentence
- each group ends with a positioning sentence
- the reader can state how this paper differs from closest prior work
