# Method / Approach Review

## Review job

Check whether the Method section makes the mechanism understandable, motivated, and tied to later evidence.

## Checks

Expect each core module to answer:

- what problem it solves
- how it works
- why it is necessary
- which result validates it

Block if:

- method text introduces unsupported theoretical or performance claims
- method claims a central mechanism that no experiment validates
- notation or definitions are so unclear that claims cannot be judged

Revise if:

- modules are listed without motivation
- design choices are described but not justified
- implementation detail is confused with contribution
- overview figure or section map is missing when method is complex

## Output focus

Separate clarity issues from evidence-support issues.
