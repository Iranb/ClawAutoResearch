# 安装指南

这页只讲一件事：

“怎么把 `ClawAutoResearch` 安装好，并确认它真的能用？”

如果你已经装好了，下一步直接去看 [使用指南](./usage.md)。

## 1. 本地仓库准备

在仓库根目录执行：

```bash
npm install
bash install.sh
```

这一步的目标不是跑项目，而是把插件、脚本和依赖准备到可用状态。

## 2. 文档站本地预览

如果你想先确认文档入口没问题：

```bash
npm run docs:dev
```

如果你只想验证文档站能构建：

```bash
npm run docs:build
```

## 3. OpenClaw / Discord 使用前要确认什么

如果你要在真实 workflow 会话里使用，还需要确认：

- 插件已经被 OpenClaw 加载。
- 当前会话是 workflow-enabled 的入口，不是普通聊天入口。
- 当前会话具备工作流工具权限。

## 4. 怎么判断“装好了”

至少确认下面几点：

- 仓库里没有因为安装缺依赖而报错。
- 你能正常运行文档命令或插件相关命令。
- 后续调用 `/auto-research` 或 `/auto-review` 时，不会在第一步就因为插件未加载而失败。

## 5. 常见误区

### 只装依赖，不跑安装脚本

这样经常会导致插件虽然有代码，但没有真正接进目标环境。

### 在假入口里测试 workflow

很多“命令没生效”的问题，其实不是安装失败，而是你在一个不会触发 workflow runtime 的入口里测试。

### 一安装完就直接调试复杂项目

第一次建议先用一个简单主题做一次最短路径验证，再进入真实项目。
