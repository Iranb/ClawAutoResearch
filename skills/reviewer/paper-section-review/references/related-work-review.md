# Related Work Review

## Review job

Check whether Related Work positions the contribution fairly and clearly.

## Checks

Expect:

- strongest relevant baselines
- grouping by method family, task, assumption, or mechanism
- fair description of prior work
- clear distinction between this paper and closest work

Block if:

- prior work is materially misrepresented
- a strongest baseline is hidden in a way that affects novelty or evaluation
- citation behavior looks fabricated or unverifiable

Revise if:

- section is mostly paper-by-paper catalog
- difference from prior work is rhetorical rather than technical
- section overclaims "first" or "unlike all prior work"

## Output focus

Name the missing line of work or the paragraph that needs positioning repair.
