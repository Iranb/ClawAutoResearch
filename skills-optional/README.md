# Optional Skills

This directory holds skills that are intentionally **not loaded by default** in the main OpenClaw Research workflow.

Use it for:

- niche utilities
- ingestion helpers
- exploratory ideation tools
- one-off scraping or conversion helpers

Current optional set:

- `skills-optional/researcher/`

Design rule:

- `skills/<agent>/` should stay focused on the default workflow for that agent
- `skills-optional/<agent>/` can contain useful extras without increasing the default agent surface area
