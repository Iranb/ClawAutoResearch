# Introduction

Use this file when drafting or revising the Introduction.

## Section job

The Introduction should move the reader from:

```text
important problem -> unresolved gap -> why the gap is hard -> paper action -> evidence-backed contributions
```

## Five-paragraph skeleton

```text
Paragraph 1: Why the problem matters now.
Paragraph 2: What prior work achieves and still misses.
Paragraph 3: Why the gap is technically hard.
Paragraph 4: What this paper does and why the idea can work.
Paragraph 5: Concrete contribution list.
```

## Opening paragraph template

```text
[Task / problem] is important because ...
However, in [setting / condition], existing approaches still fail to ...
The core difficulty is ...
This leaves a key open question: ...
```

## Contribution list template

```text
Our contributions are threefold.
First, we ...
Second, we ...
Third, we ...
```

## Hard rules

- Do not write a generic background survey.
- Do not put all Related Work in the Introduction.
- Do not introduce method details before the reader understands the gap.
- Do not use "first" / "novel" unless the claim is defensible.
- Contribution bullets must match Results and Conclusion.

## Ready check

The Introduction is ready only if:

- the gap is visible by paragraph 2
- the paper action is visible before contribution bullets
- every contribution has evidence later in the paper
- a non-author reader can explain what the paper does
